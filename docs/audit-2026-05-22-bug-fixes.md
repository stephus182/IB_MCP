# Bug Fix Audit Report — IBKR MCP Dashboard
**Date:** 2026-05-22
**Reviewer:** superpowers:code-reviewer
**Engineer:** Claude Sonnet 4.6

---

## Overview

Full code review of all dashboard components (IBKR, Google Drive, TradingView, backtest sandbox, Claude chat). 11 bugs identified and fixed. The backtest pipeline was entirely non-functional before this audit — 100% of attempts would have failed.

---

## Findings

### #1 — Critical | `tools/backtest.py` | `_write_` guard absent

**Root cause:** RestrictedPython rewrites every assignment to call `_write_()`. Without it in globals, every strategy raised `NameError` at first assignment — 100% failure rate.
**Fix:** Added `glb["_write_"] = lambda x: x` to `_build_globals`.
**Test:** SMA crossover strategy with `df.loc[...] = 1` and `df['signal'] = 0` assignments → PASS.

---

### #2 — High | `components/chat.py` | Cache key mismatch

**Root cause:** `fetch_market_data` saves with key `SYMBOL_TIMEFRAME_PERIOD_END` (e.g. `AAPL_1D_1Y_2026-05-22`) but `run_backtest` and `check_cache` tools sent date strings as `start`, building a key that never matched.
**Fix:** Changed both tool schemas and handlers to use `period` (e.g. `"1Y"`) instead of `start` date string.
**Test:** Keys generated by fetch and load paths confirmed identical → PASS.

---

### #3 — High | `tools/backtest.py` | Missing builtins

**Root cause:** `safe_builtins` omitted `list`, `dict`, `set`, `tuple`, `min`, `max`, `sum`, `enumerate`, `map`, `filter`, `any`, `all`, `sorted`, `reversed`, `round`, `abs`, `isinstance`, `len`. Also `print` requires RestrictedPython's `PrintCollector` via `_print_`.
**Fix:** Extended `__builtins__` with all missing builtins; imported and set `glb["_print_"] = PrintCollector`.
**Test:** Strategy using `enumerate`, `list`, `map`, `min`, `max`, `sum`, `print`, `any`, `sorted` → PASS.

---

### #4 — Medium | `tools/gdrive_cache.py` | Dead staleness check

**Root cause:** `check_cache` only triggered staleness when `end == "today"` (literal). `chat.py` always passes today's ISO date string, so intraday data was cached permanently.
**Fix:** Condition changed to `end in ("today", str(date.today()))` — catches both forms.
**Test:** 4 cases (fresh/stale × date-string/literal) all correct → PASS.

---

### #5 — Medium | `components/chat.py` | Unhandled Anthropic API errors

**Root cause:** Any `APIError` (429, 529, 500, network) inside the streaming loop propagated uncaught, crashing the Streamlit UI thread with a raw traceback.
**Fix:** Wrapped the `while True` streaming loop in `try/except anthropic.APIError` — error displayed cleanly in the chat bubble.
**Test:** Syntax check + exception hierarchy verified → PASS.

---

### #6 — Medium | `tools/backtest.py` | Misleading docstring

**Root cause:** Docstring described accepting `signals` variable or `positions` column; only `df['signal']` is actually checked, causing Claude to generate incompatible code.
**Fix:** Docstring updated to state exactly what is required.
**Test:** Syntax check → PASS.

---

### #7 — Medium | `tools/backtest.py` | NaN Sharpe ratio

**Root cause:** All-zero or NaN strategy returns produce `NaN` Sharpe which is not valid JSON and renders as `"nan"` in the UI.
**Fix:** `sharpe = float(sharpe_raw) if sharpe_raw == sharpe_raw else 0.0` (NaN self-inequality guard).
**Test:** Flat price series (zero std, zero mean) → `sharpe=0.0`, not NaN → PASS.

---

### #8 — Low | `config.py` | Overly broad Google Drive scope

**Root cause:** `drive` scope grants read/write access to all of the user's Drive. Only `drive.file` (app-created files only) is needed.
**Fix:** Scope changed to `drive.file`; stale `token.json` deleted to force re-auth with new scope on next launch.
**Test:** Config value verified → PASS.
**Action required:** Next `ibkr_mcp` launch will open a Google OAuth consent screen — approve once.

---

### #9 — Low | `app.py` | No Retry Drive button

**Root cause:** Drive auth failures had no recovery path in the UI without a full Streamlit restart.
**Fix:** Added `↺ Retry Drive` button mirroring the existing `↺ Retry IBKR` button — only shown when Drive is red.
**Test:** Syntax check → PASS.

---

### #10 — Low | `tools/gdrive_cache.py` | Manifest re-downloaded on every cache check

**Root cause:** `_load_manifest()` fetched `manifest.json` from Drive unconditionally, causing ≥2 API round-trips per `fetch_market_data` call.
**Fix:** Added 60-second in-memory TTL (`_manifest_loaded_at` timestamp). Cache hit skips the Drive call entirely.
**Test:** 3-call simulation — 2 hits within TTL (0 Drive calls), 1 call after expiry (1 Drive call) → PASS.

---

### #11 — Low | `requirements.txt` | Streamlit version pin too loose

**Root cause:** `streamlit>=1.35.0` allows installs that lack `st.iframe` (added in 1.45.0), causing `AttributeError` at runtime.
**Fix:** Pin raised to `streamlit>=1.45.0`.
**Test:** Verified → PASS.
